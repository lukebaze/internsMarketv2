## 2. Segment Profiles

### NON-TECH Segment

**Summary:** Professionals in high-meeting, high-email, high-admin environments. Not builders—they need AI that replaces an assistant or junior analyst. Value reliability and time-saving over feature depth. Most likely to need ops-flavored interns.

| Dimension | Detail |
|-----------|--------|
| Shared pain points | Information overload, manual formatting, scheduling chaos, lack of admin leverage |
| Shared motivations | Save 5–15h/week, look more organized to stakeholders, reduce cognitive load |
| Price sensitivity | Medium — compares vs. hiring VA ($500–$1500/mo) |
| Decision speed | Slow (1–2 weeks); needs internal approval or partner buy-in |
| Preferred channels | LinkedIn, productivity newsletters, podcast ads, referrals |
| Best intern matches | Sam Patel (Ops/Meetings), Luna Sage (Life Coach), Nadia Okafor (Research), Jordan Lee (Content Marketing) |

---

### WEB2 Segment

**Summary:** Digital professionals running lean operations across marketing, e-commerce, SEO, dev, and customer success. Tool-savvy and AI-curious. Need interns that slot into existing workflows (Notion, Slack, GitHub, Shopify). Highest volume segment.

| Dimension | Detail |
|-----------|--------|
| Shared pain points | Scale bottleneck (1 person doing job of 3), repetitive output tasks, tool fragmentation |
| Shared motivations | Output velocity, consistent brand voice, less context-switching |
| Price sensitivity | Low-Medium — already paying for 5–10 SaaS tools; $29.99/mo is cheap by comparison |
| Decision speed | Fast (3–7 days); individual decision makers with card on file |
| Preferred channels | Twitter/X, ProductHunt, dev/marketing Discord, YouTube tutorials |
| Best intern matches | Jordan Lee (Content), Mia Santos (Social), Nadia Okafor (Research), Ethan Hale (Code Review), Alex Rivera (QA), Priya Sharma (Data Analyst), Sofia Reyes (UX) |

---

### WEB3 Segment

**Summary:** Crypto-native traders, analysts, and fund managers operating in high-speed, high-stakes environments. Need real-time data interns, not content writers. Small but high-LTV segment if product-market fit achieved. Highly referral-driven.

| Dimension | Detail |
|-----------|--------|
| Shared pain points | Signal-to-noise ratio, manual on-chain monitoring, rug-pull risk, fund reporting |
| Shared motivations | Alpha edge, faster execution, automated monitoring while sleeping |
| Price sensitivity | Low — accustomed to paying for premium data tools ($50–$500/mo) |
| Decision speed | Very fast (same day); individual decision, low friction |
| Preferred channels | Crypto Twitter/X, Telegram, Discord alpha groups, YouTube crypto |
| Best intern matches | Nadia Okafor (Research), Priya Sharma (Data Analyst), Luna Sage (Life Coach for focus), Sam Patel (Ops for fund reporting) |
